FORMA — EDITABLE DESIGN FILE

Open Forma.fig in Figma using its file import option, or open it in OpenPencil.
The ZIP is a delivery bundle: extract it first, then import the .fig file.

Fonts: Inter and Space Grotesk. The fonts folder includes both font files and
their SIL Open Font License notices. Install these if your editor reports
missing fonts.

WHAT IS INSIDE

00 / Start here
01 / Foundations: color, spacing and radius variables; typography reference
02 / Components: 12 masters, with button states, chips and exercise rows
03 / Desktop: builder, active set, rest and completion
04 / Mobile: full scrolling builder, plan detail, active set, rest and completion
05 / States: empty selection, loading, request error and saved confirmation
06 / Flow & handoff: page flow and mapping to the current repository

The file contains editable text, native shapes, vector illustrations,
components, instances, auto layout controls and named variables.

DESIGN BASIS

The supplied stitch_remix_of_fitness_design_system.zip contains the KINETIX
HTML design system and its screenshot. Forma uses its charcoal/lime palette,
Space Grotesk/Inter typography and restrained control styling.

Product content and behavior come from the repository: seven body areas,
15/30/45-minute choices, 4/6/8 exercises, none/dumbbells equipment, three sets,
45-second rests, +15 seconds, skip rest, and saving a plan on this device.
The six-exercise example is generated by the repo's real planner.
Illustrations and body-map geometry come from the repo's local SVG sources.
The sample completion duration (28 minutes) is illustrative.

This is a design proposal. The app has not been restyled as part of this work.
The flow guide documents navigation; clickable Figma prototype links are not
included. The runtime map is an implementation aid, not a new C4 specification;
the repository's architecture diagrams are in docs/diagrams.

VALIDATION

Generated with OpenPencil 0.14.0, exported to its native Figma format, and
reopened with the native codec. All instance text overrides were checked after
reopening. PNG previews were rendered from the reopened .fig and visually
reviewed. Direct import into Figma itself has not been tested in this session.
See validation.json for the inventory.

EDITING AND REBUILDING

Edit Forma.fig directly for normal design work.

The source scripts remain in the repository:
  node design/build-figma.mjs
  node design/render-previews.mjs

They require an installed OpenPencil CLI and the repo's source files.
OPENPENCIL_MODULES can point to the CLI's node_modules directory.
Rebuilding replaces Forma.fig and previews; preserve manual edits separately.
